What is HTML?

Every website you have ever visited, from Google to your favourite news site, is built on HTML. In this lesson you will understand what it is and write your own first web page.

By the end you will be able to:
  • Explain what HTML is in your own words
  • Read and write an HTML tag
  • Build the basic skeleton of a web page
  • Use headings and paragraphs

1. What HTML means

HTML stands for HyperText Markup Language. That sounds complicated, but the idea is simple:

HTML is a way of labelling the parts of a page so the browser (Chrome, Firefox, Safari) knows what each part is: "this is a title", "this is a paragraph", "this is a picture".

Think of a Word document. When you make some text a "Heading" or a "Bullet list", you are labelling it. HTML does the same thing, but you write the labels yourself using short words inside angle brackets.

HTML is not a programming language. It does not calculate or make decisions. It describes what is on the page. Later, CSS makes it pretty and JavaScript makes it interactive.

2. Your first tag

Labels in HTML are called tags. Most tags come in a pair: one to start and one to stop.

<p>Hello, world!</p>

This is a paragraph. The browser shows: Hello, world!

PartWhat it is
<p>The opening tag. It says "a paragraph starts here".
Hello, world!The content. This is what people see.
</p>The closing tag. Same name, but with a /. It says "the paragraph ends here".

Together, the opening tag, the content and the closing tag are called an element.

Common mistake: forgetting the / in the closing tag, or forgetting to close the tag at all. If your page looks strange, check your closing tags first.

3. Headings and paragraphs

Headings go from <h1> (the biggest, most important) down to <h6> (the smallest). Use one <h1> per page for the main title.

<h1>My Favourite Foods</h1>
<h2>Fruits</h2>
<p>I love mangoes and pineapples.</p>
<h2>Drinks</h2>
<p>I enjoy fresh juice on hot days.</p>

One main title, two smaller headings, and a paragraph under each.

Two small facts to remember: the browser puts each paragraph on its own line, and extra spaces and blank lines in your code are ignored. Only the tags decide how things look.

4. The skeleton of a web page

Every complete web page has the same basic structure. Memorise this one, you will use it hundreds of times.

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="utf-8">
    <title>My First Page</title>
  </head>
  <body>
    <h1>Hello!</h1>
    <p>Welcome to my page.</p>
  </body>
</html>
LineMeaning
<!DOCTYPE html>Tells the browser "this page uses modern HTML".
<html>Wraps the whole page. lang="en" says the page is in English.
<head>Behind-the-scenes information. Visitors do not see this part.
<title>The name shown on the browser tab.
<body>Everything visitors can see: text, images, buttons.

Notice the tags sit inside each other, like boxes inside boxes. The indentation (spaces at the start of lines) is not required, but it makes your code much easier to read.

6. Quick quiz

Summary

  • HTML labels the parts of a web page using tags.
  • Most tags come in pairs: <p> opens and </p> closes.
  • <h1> to <h6> are headings, <p> is a paragraph.
  • Every page has html, head and body. Visitors see only what is in the body.
